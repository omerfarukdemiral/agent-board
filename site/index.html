Nasıl kullanılır

  1. Klonla ve bir kez kur

    setup arayüzü derler ve claude-board komutunu PATH'e ekler.

    git clone https://github.com/omerfarukdemiral/agent-board ~/tools/agent-board && cd ~/tools/agent-board && npm run setup

  2. Board'u aç, oturumların zaten orada

    Board localhost:4317 adresinde açılır. O an açık olan Claude Code oturumları, nasıl başlatılmış olurlarsa olsunlar, kurulumsuz belirir: agent'lar, görevler, sohbet ve maliyet.

    npm --prefix ~/tools/agent-board start

  3. Tam kontrol için claude-board

    Projende claude yerine claude-board yaz. İzinleri ve soruları panodan cevaplar, çalışan oturuma panodan yazarsın. Açılıştaki channels uyarısını Enter ile geç.

    cd ~/projem && claude-board
Agent haritası
Orkestratör ortada, subagent'lar etrafında. Yakınlaştır, kaydır; her agent'ın durumu, o anki aracı ve maliyeti.
Inbox
İzin istekleri, Claude'un senin yerine verdiği kararlar ve okuman gereken notlar. Terminalden de cevaplanabilir, hangisi önce gelirse.
Şimdi ekranı
Bütün projeler tek bakışta: çalışanlar, seni bekleyenler, son hareket edenler.
Görev akışı
Yapılacak, Çalışılıyor, Review, Bitti. Her kartta işi yapan agent.

Sunucu yalnızca 127.0.0.1'de çalışır, dışarı istek atmaz; onaylar sayfaya özel bir anahtarla korunur. Kurulumsuz izleme salt okunurdur; board'dan mesajlaşma Claude Code'un deneysel channels özelliğine dayanır.
